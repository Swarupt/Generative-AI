# Assignment 5: Python - Importing, Creating Modules & Packages

## Overview

This assignment focuses on creating and importing Python modules and packages.

The programs demonstrate how to organize Python code into separate modules and a package and use functions from them.

## Topics Covered

- Creating Python modules
- Importing modules
- `import module`
- `from module import function`
- Creating Python packages
- `__init__.py`
- Importing functions from a package
- Using functions from imported modules
- Basic function calls
