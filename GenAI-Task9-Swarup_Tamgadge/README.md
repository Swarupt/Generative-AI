# Assignment 9: NumPy — Mathematical & Statistical Operations

## Overview

This assignment focuses on using NumPy to perform mathematical computations, array manipulations, aggregation, and statistical analysis. It builds a foundation for future learning in Pandas, Machine Learning, and Data Science.

## Topics Covered

- Creating 1D and 2D NumPy arrays
- Array shape and data types
- Element-wise mathematical operations
- NumPy mathematical functions
- Square root, exponential, and logarithm
- Sum and cumulative sum
- Row-wise and column-wise aggregation
- Mean, median, variance, and standard deviation
- Minimum, maximum, and range
- Percentiles and sorting
- Boolean indexing
- Basic sales data analysis

## Tasks

### Task 1 — Creating NumPy Arrays

Created 1D and 2D arrays using `np.arange()`, `np.array()`, and `reshape()`. Displayed the shape and data type of each array.

### Task 2 — Mathematical Operations

Performed addition, subtraction, multiplication, division, and exponentiation on two NumPy arrays. Also demonstrated `np.add()` and `np.subtract()`.

### Task 3 — Mathematical Formulas

Used NumPy functions to calculate square roots, exponential values, natural logarithms, the total sum, and cumulative sums.

### Task 4 — Aggregation Operations

Calculated row-wise sums, column-wise sums, minimum, maximum, and overall mean for a 2D array.

### Task 5 — Statistical Operations

Calculated mean, median, population variance, population standard deviation, minimum, maximum, and range for student marks.

### Task 6 — Percentiles and Sorting

Sorted student marks, calculated the 25th, 50th, and 75th percentiles, and identified students scoring above the average.

### Task 7 — Sales Analysis

Analyzed seven days of sales data to calculate total weekly sales, average daily sales, highest and lowest sales, standard deviation, and days with above-average sales.
